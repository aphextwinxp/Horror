# ЭХО — IndieHorrorVR

Хоррор для VR на **WebXR** (Three.js). Соқыр жаратылыс «Тыңдаушы» тек дыбысқа әрекет етеді: үнсіздік — сенің қаруың, шу — қауіп.

> **v0.3** — толық қазақ тілі + байытылған интерьерлер.

## Запуск

Сборка не нужна (Three.js подключается с CDN через import map).

```bash
npm start            # или: python3 -m http.server 8000
```

Открой `http://localhost:8000` — кнопка **«ПК-де ойнау»** запускает тестовый режим без шлема.
Для Meta Quest нужен HTTPS: Netlify / GitHub Pages / Cloudflare Pages, либо `adb reverse tcp:8000 tcp:8000` и `http://localhost:8000` в браузере шлема.

## Управление

| | VR (Quest) | ПК (тест) |
|---|---|---|
| Жүру | сол стик (жеңіл = тыныш) | WASD (Shift — тыныш) |
| Бұрылу | оң стик (snap 30°) | тышқан |
| Телепорт | сол стик клигі → режим, оң стик алға + жіберу | — |
| Отыру | шынымен отыру | Ctrl / C |
| Алу / лақтыру | хват (grip) | E / ЛКМ |
| Шам / плёнка | курок | F |
| Рацияны басу | X түймесі | — |
| **Жеңіл режим** | оң стик клигі | — |

## Сюжет және өту

**Акт I.** Шам → магнитофон (жазба 14, жаратылыс оянады) → сақтандырғыш зертханада → щиток → есік.  
**Акт II.** Шлюз → тұрғын блок (жазба 22 Мартаны ашады, кілт-карта бөлмелердің бірінде) → оқығыш → сервер бөлмесі (стеллаж-жылан, жазба 31, дерек пластинасы).  
**Акт III.** Таңдау:
- Пластинаны резонанс камерасының консоліне салып **25 секунд толық үнсіздік** сақтау → **«Үнсіздік»**.
- Егер жаратылыс финалда сені ұстаса → **«Жаңғырық»**.
- Камераға бармай, пластинамен шлюздегі лифтке оралу → жасырын аяқталу **«Жазба»**.
